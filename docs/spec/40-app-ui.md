## 状態管理
- Engine は Web Worker で実行（`apps/web/src/engine.worker.ts`）。UI とは Comlink 風の薄い RPC。
- UI は Zustand ストアに最新の `HallProjection` を持ち、前面時は 1Hz で更新。盤面アニメーションは Pixi 側が補間。
- Action（購入等）は「UI → Worker に appendAction(t=now) → advance(now) → 新 Projection」の順。IndexedDB 追記が成功してから確定。
- 時刻 `now` は UI スレッドの `Date.now()` を渡す（Core は時刻を持たない）。端末時計の巻き戻しを検知したら
  （now < 最終 advance 時刻）前進を止めて警告表示。

## 前面/背面
- `visibilitychange` で `presence` Action を記録。復帰時は `advance(now)` → `AwaySummary` → サマリー表示。
- 背面では何も動かさない（Service Worker も Engine を回さない）。
