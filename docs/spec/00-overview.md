# 00 Overview

## コンセプト
**良い行動（運動・トレーニング）をすると、パチンコホールの「営業時間」がもらえる放置ゲーム。**
営業時間がある間、盤面の役物が回って玉が増える（閉じていても進む）。玉は
「自分（ホール）の強化」にも「パチンコを打つ（抽選）」にも使える。Cookie Clicker / Revolution Idle 型（D-011）。

## ループ
```
行動 ──(ショートカット / チェックイン / 自己申告)──▶ 受け取り台帳 ──▶ 営業時間（燃料）＋メダル
営業時間 ──▶ 役物が回転 ──▶ 玉 ─┬─▶ 強化（役物Lv・覚醒・放置効率 …）
                                └─▶ 打つ → ヘソ → 抽選 → 大当たり → 玉＋メダル
累計玉 ──▶ 閉店（周回）──▶ 常連P（永続バフ）
```

## 行動の入力（spec/30〜32）
| 入力 | 手段 | 信頼度 |
|---|---|---|
| 歩数・距離 | 利用者が iOS ショートカットを実行 → 受け取りコード → PWA に貼る（D-012） | health |
| スマホを持たないトレーニング | 開始/終了で前面位置取得、登録地点か OSM 施設の範囲内（D-013） | checkin |
| ToDo・習慣 | 自己申告 | self |

## サーフェス
| 場所 | 内容 |
|---|---|
| PWA（ホーム画面に追加） | すべて。盤面描画・強化・受け取り・チェックイン・統計 |
| iOS ショートカット | ヘルスケアの読み出しと受け取りコード生成のみ |
| アイコンのバッジ | 前面時に「未確認の大当たり数」等を `setAppBadge`（対応環境のみ） |
| （任意・後期）Web Push | 大当たり予定時刻の通知（spec/41, D-014） |

## 対象
- 主対象: iPhone（iOS 26.x Safari、ホーム画面の Web アプリ）。Android / PC ブラウザでも動く（ショートカット以外）。
- 個人利用＋GitHub でソース公開。配信は Vercel（URL を開いてホーム画面に追加するだけ）。

## やらないこと（Non-goals）
- 有料 Apple Developer Program を要するもの、ネイティブアプリ（D-010）
- 背景での位置追跡・歩数の自動取得（Web では不可）、勉強写真・スクショ OCR（D-015）
- MVP でのサーバー・アカウント・課金・ランキング（D-014）
- 玉同士の衝突（D-003）
- 実在機種の版権素材（図形・自作素材のみ）
- 換金・現金等価物（シミュレーターであり賭博ではない）

## MVP の範囲
- Core: 物理・Atlas・抽選（特図1のみ、保留4、ST 方式）・放置経済（役物・覚醒・閉店）
- 入力: ショートカット（歩数・距離）、トレーニングチェックイン、自己申告
- 画面: ホール（盤面）、強化、受け取り、チェックイン、統計、設定、セーブの書き出し/読み込み
- 演出: 通常/SP/激アツ/確定の4演出、音と光（CueSheet）
- 後回し: 新台入替（周回2段目）、実績、設定6チケット、Web Push、Strava・GitHub 連携
