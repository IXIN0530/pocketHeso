# 00 Overview

## コンセプト
歩くと玉が自動発射され、盤面を物理演算で転がり、ヘソに入ると抽選が始まる。
アプリは開かない前提。状態は通知欄・ロック画面に常駐し、激アツ時だけ割り込んで演出を見せる。

## サーフェス（16e = DI 非搭載）
| サーフェス | 何を見せるか | 更新 |
|---|---|---|
| Live Activity（ロック画面/通知センター） | 盤面ダイジェスト、保留4つ、変動中/大当たり中の状態、持ち玉 | 約15秒 |
| ロック画面 accessoryInline | 保留 `◉◉○○`（色付き）＋モード | 1分刻み（先読みタイムライン） |
| ロック画面 accessoryRectangular | 保留＋回転数＋当たり回数 | 同上 |
| バナー（AlertConfiguration） | 保留変化・疑似連など「中アツ」 | イベント時 |
| AlarmKit | 「激アツ」「確定」の予告。サイレント貫通 | 予測時刻に予約 |
| 通知コンテンツ拡張 / アプリ | フル演出（SpriteKit） | 開いた時 |

## やらないこと（Non-goals）
- 通知欄での玉1個単位のリアルタイム描画（OS 制約で不可）
- ステータスバー領域への描画（DI なし・非脱獄で不可）
- システム CPU 使用率の入力（取得不可）
- 玉同士の衝突（D-003）
- サーバー・APNs・課金・アカウント
- 実在機種の版権素材（プレースホルダーの図形・自作素材のみ）

## MVP の範囲
特図1（ヘソ）のみ、保留最大4、確変は ST 方式（電サポ・電チューなし）、アタッカーは簡略出玉計算。
電チュー・右打ち・V入賞は MVP 後の拡張（P2 の拡張ポイントとして型だけ用意）。
