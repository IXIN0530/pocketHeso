### P11-T2 閉店カード: 常連ランク・常連P の計算式を見せる
Owner: Claude Code（Sonnet） | Read: spec/25-core-prestige-tree（常連ランクと常連P・画面）, spec/23-core-economy（閉店）
Do:
- Core（表示用の値を足すだけ。保存・golden・経済の式は変えない）: `ShopCloseView` に
  `totalTotal`（これまでの累計玉）・`nextBallsAt`（玉由来が +1 になる累計玉 = (byBalls+1)³ × divisor。掛け算で出す）・`nextMedalsAt`（行動由来が +1 になる累計メダル = (byMedals+1) × medalsPerPoint）を足す。
  `economy-state.ts` の該当箇所で計算し、テスト（境目の値・byBalls 0 の時）を足す。禁止演算は使わない。
- web `shop-screen.tsx` の閉店カードの説明を次の形に（数値は今の値で埋める。`<details>` で「計算のしかた」を畳んでよい）:
  - 「ランクの上がり幅 = min(玉由来, 行動由来) − 今のランク」
  - 「玉由来 n = ∛(これまでの累計玉 ÷ 120億) の切り捨て。今 これまで X玉 → n。次の +1 は Y玉（あと Z玉）」
  - 「行動由来 m = 累計メダル ÷ 28 の切り捨て。今 M枚 → m。次の +1 は N枚（あと k枚）」
  - 「閉店の条件は**今回**の累計玉が 100億。玉由来は**これまで**の累計玉（閉店で戻らない）」— 2つの累計玉を必ず書き分ける。
  - 「常連P = ランク +g × 10 ＋ 累計玉の段（今回の累計玉が 1000億・1兆・… を超えた数）＋ 口コミ」。今の内訳（`closeBreakdown`）も並べる。
  - 120億・28・10・段の値は economy JSON から読む（文言に直書きしない）。
- spec/25 の「画面」に閉店カードの説明の形を2行で足す。
- web のテスト: 説明の文字列（玉由来・行動由来の「次の +1」・2つの累計玉の書き分け）。
Accept:
- [ ] `scripts/test.sh core`（golden 不変）・`scripts/build.sh`・`scripts/test.sh all` が通る
