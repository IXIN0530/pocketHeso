# P12-T2 常連ツリー試算のやり直し（休業: 閉店 → 買う → 開店。spec/25「検証」1・2・3・5・6・7）

実行日 2026-10-14。条件: seed 1、`resources/economy/default.json` の現行値（値の調整なし）。比較元は `econ-20261013-p10.md`（P10-T5。閉店 → 開店を同じ t で出し、買い物は次のステップ）。
機種: L=light-middle-01 / R=rush-middle-01 / T=lt-middle-01。コマンドは p10 の記録と同じ（`scripts/sim.sh econ ...`）。

## pachisim（econ.ts）の変更点
- greedy: 閉店したステップで `close` → 常連P（今の P + 閉店で得る P。`treeClosePoints` で手元計算）で買える物を greedy で全部買う（`treeBuy`）→ 同じ t で `open`。starter・keep・開店ダッシュが今回の開店から効く。
- `--tree off` は `close` → `open` を続ける（従来どおり）。`--tree all` も `close` → `open`（買う物がない）。
- 閉店直後の役物の覚醒・購入だけは、手元の写しが開店後の実状態（keep・starter）とずれるので次のステップに回す（D-105 のうちツリーの購入を回す部分はやめた。役物の部分は必要なので残した）。
- bot の予備: オート所持中は玉を 300 残して買う（BUY_RESERVE）が、keep でオートが残ると「開店直後の持ち玉 100 < 予備 300」で何も買えず止まった（検証 3 の1週目が off の 0.82倍・玉の累計が 1/100）。**役物 Lv が 1 つもない間は予備を残さない**に変更（off・all の結果は変わらないことを確認）。DECISIONS 候補。

## 判定（Opus 確定）
- 1・2・7: 前回と一致 → T1（休業・開店）に誤りなし。7 の T 1.360 は既存の持ち越し（P8-T9、ツリーと無関係）。
- 3: OK。1週目から greedy が off を上回る（x1.10〜1.23）。休業中に買う分が1周早く効いている。
- 5・6: p10 と同値の NG（T r74 w3 6.08・R r180 w4 7.00）。`--tree all` は休業の影響を受けないので P12 の新しい NG ではなく、P10-T5 の Blocker（人間判断待ち、A そのまま推奨）と同じもの。値は変えない。
- bot の予備の変更は D-109。
