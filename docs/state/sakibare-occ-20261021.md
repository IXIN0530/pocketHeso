# 抽選カスタムの実効の占有率（P13-T8b, 2026-10-21）
`customSakibareRates`（@ph/fx）の値。先バレは必ず変化保留 → 最終色が白の保留には先バレしない。
信頼度 r はどこでもカスタムの値（40/90/100%）のまま。占有率 o = min(カスタムの o, 当たりの白以外の割合, ハズレの確率 ≤ 1 で満たせる最大)。
a = 白以外の当たりが先バレする確率、b = 白以外のハズレが先バレする確率（色によらず一定）。p は取得時のモードの当選確率。

| 機種 | モード | 1/p | 当たりの白以外 | sb40 o（a / b） | sb90 o（a / b） | sb100 o（a / b） |
|---|---|---|---|---|---|---|
| light | 通常 | 185 | 95% | 95%（1.00 / 0.60） | 90%（0.95 / 0.04） | 60%（0.63 / 0） |
| light | ST | 39.9 | 60% | **60%**（1.00 / 0.75） | **60%**（1.00 / 0.06） | 60%（1.00 / 0） |
| rush | 通常 | 328 | 95% | 95%（1.00 / 0.60） | 90%（0.95 / 0.04） | 60%（0.63 / 0） |
| rush | ST | 39.9 | 60% | **60%**（1.00 / 0.75） | **60%**（1.00 / 0.06） | 60%（1.00 / 0） |
| lt | 通常・時短 | 337 | 95% | 95%（1.00 / 0.60） | 90%（0.95 / 0.04） | 60%（0.63 / 0） |
| lt | ST・LT | 39.9 | 60% | **60%**（1.00 / 0.75） | **60%**（1.00 / 0.06） | 60%（1.00 / 0） |

- 通常/時短はカスタムの o をそのまま満たす。ST/LT は当たりの 40% が白なので o の上限が 60%（太字が下がった所）。r 優先・o は下がってよい、の意図どおり。
- ST/LT でもカスタムの o を満たすのは P13-T8c（人間の要望 10/21）。見積もり（ST, p = 1/39.9）:
  - 白の**当たり**だけ先バレ可にすると: sb90・sb100 は満たせる。sb40 は b が o に比例し o = 60% で 0.75 なので、o = 95% では b ≈ 1.19 > 1 → **o ≈ 80% が上限**。
  - sb40 で 95% を満たすには、白の**ハズレ**の一部にも先バレが要る（先バレは全保留の約 5.9%、白以外のハズレは約 3.0% しかない）。
  - どちらも「最終色が白の保留が割れて色が出る」= 見せる色 `plan.final` が Core の色と違う保留ができる。色の見かけの信頼度が ST/LT だけ少し変わる。
