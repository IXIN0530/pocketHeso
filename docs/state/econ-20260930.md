- 1・2 は不変で OK（2 は出玉と打ち出し時間だけで決まり、ラウンド時間に依らない）。
- 3 は悪化（2-5分から遠のく）。初当たり率は同じで、外れだけの試行はラウンド時間に依らないため、当たりを引いた試行の時間が延びた分（大当たり中の出玉で打ち続ける時間など。内訳は未調査）。
- EV は ev-hours 1000 の打ち切り時刻の差でわずかに揺れるだけ（出玉の期待値そのものは `sim run` で不変）。
- 初閉店 5日目・覚醒 4日目は3機種とも不変。機種値は変えず（P9-T1 Do）、既存のバランス持ち越しと合わせて人間判断。
