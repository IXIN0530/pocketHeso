## 判定
- EV（初期）: 3機種とも基準内（1.05〜1.15、lt 1.03〜1.17）で6桁一致。全強化も +0.0004 以内（rush 1.218・lt 1.360 の基準超えは既存の持ち越し P8-T9）。
- 標準 1〜7日の表（玉・perSec・内訳・閉店）は3機種とも**前後で完全に同じ**。行動 56〜63% の基準外（25〜45%）は変更前からの既存の持ち越しで、今回の変更による動きはない。
- 色付き保留は RUSH 中の変動の一部（ST 表で色付き約1/22）なので、RUSH 1回が約1%延びるだけ。経済の値は変えない。
