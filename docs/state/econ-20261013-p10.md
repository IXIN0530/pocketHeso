## 手順メモ（実装の判断）
- `--start-rank n`: `IdleEconomy.restore` で regular=n・medalsEarned=n×28・totalTotal=ランク n の閉店に釣り合う量（divisor×n³ を ballPoints ≥ n まで微増）・points=0。玉側が 0 だと閉店が一切起きず検証 6 の「閉店は週1〜3回」が測れないため totalTotal も補った（spec は「累計獲得メダル n×28」のみ）。
- `--tree all`: 全ノードを購入列に入れ pointsEarned=Σcost、points=0。`--bantou on` なら bantouOn=true。greedy では番頭さんを所持した回に `bantou on` を積む。
- 閉店直後は手元の写しが実状態（保持・starter Lv）とずれ、買いが insufficient-balls で rejected になるため、ツリー使用時（greedy/all）は閉店したステップの覚醒・購入を次のステップ（前面5秒/背面60秒後）に回す。off は従来どおり（既存の挙動不変）。
- Engine の入力は次の advance で処理されるので、greedy は手元で所持・段・P を更新しながら選び、同一ステップに treeBuy を積む。
