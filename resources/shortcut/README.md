# PocketHeso Sync（iOS ショートカット）作成手順

仕様: docs/spec/31-shortcut-health.md。ショートカット名は **`PocketHeso Sync`**（PWA がこの名前で起動する）。
iCloud 共有リンク: （P0-T3 の実機確認後に記入）

## 0. 最小版（P0-T3 の往復確認用）
先に往復（PWA → ショートカット → PWA → 貼り付け）だけ確かめる。
1. 「テキスト」: `PH1.eyJ2IjoxfQ.0000000000000000`（`{"v":1}` の Base64）
2. 「クリップボードにコピー」
3. 「通知を表示」: `PocketHeso に戻って貼り付けてください`

ホーム画面の PWA（プレビュー版）を開き、下部の「spike: shortcut」→「ショートカットを開く」→ 通知後に PWA へ戻る →「貼り付け」。
デコード欄に `{"v":1}` が出れば成功。

## 1. 本番版

### 1-0 先に知っておく操作
- **アクションの追加**: 画面下の検索欄「アクションを検索」にアクション名を入れ、出てきたものをタップ（一番下に追加される）。
  長押しでドラッグすると順番を変えられる。
- **青い文字**はタップして値を選ぶ設定項目。**灰色の文字**（例: 「テキスト」）はタップして入力する欄。
- **変数を入れる**: 入力欄をタップ → キーボードの上に出るバーの「変数を選択」（または候補のバブル）→ 入れたい変数をタップ。
  入れた変数はバブル（色付きの角丸）で表示される。
- **変数のプロパティ**（例: ワークアウトの「開始日」）: 入れたバブルをタップ → 一覧から項目を選ぶ。
- **名前付き変数**: この手順では「変数を設定」アクションで名前を付け、後で名前で選ぶ。途中結果の取り違えを防ぐため。
- 表記は iOS 26 日本語版を想定。名前が少し違う場合は（ ）内の英語名に近いものを選び、どこが違ったかメモしておく。
- 各ブロックの最後に **「確認」** がある。そこで一度 ▶ で実行し、表示が合っていれば「結果を表示」アクションを削除して次へ進む。

### 1-1 鍵
| # | アクション | 設定 |
|---|---|---|
| 1 | テキスト（Text） | `abcdefghijklmnop`（試験用の仮の鍵。本番では PWA が表示する16文字に置き換える） |
| 2 | 変数を設定（Set Variable） | 変数名: `鍵`、入力: 1 の「テキスト」 |

### 1-2 日ごとの歩数・距離（今日・昨日・一昨日の3日分）
「繰り返す」の中は **3回** 実行される。1回目が今日、2回目が昨日、3回目が一昨日。

| # | アクション | 設定 |
|---|---|---|
| 3 | 繰り返す（Repeat） | 回数: `3`。以下 4〜22 は「繰り返す」と「繰り返しの終了」の**間**に入れる |
| 4 | 計算（Calculate） | 「繰り返しインデックス」 `−` `1`（1回目→0、2回目→1、3回目→2） |
| 5 | 日付を調整（Adjust Date） | 対象の日付: 「現在の日付」、操作: **減算**、値: 4 の「計算結果」、単位: **日** |
| 6 | 日付を調整 | 対象の日付: 5 の「調整済みの日付」、操作: **日の始まりを取得**（Get Start of Day） |
| 7 | 変数を設定 | 変数名: `開始`、入力: 6 の「調整済みの日付」 → その日の 0:00 |
| 8 | 日付を調整 | 対象の日付: 変数 `開始`、操作: **追加**、値: `1`、単位: **日** |
| 9 | 変数を設定 | 変数名: `終了`、入力: 8 の「調整済みの日付」 → 翌日の 0:00 |
| 10 | 日付をフォーマット（Format Date） | 日付: 変数 `開始`、日付フォーマット: **カスタム**、フォーマット文字列: `yyyy-MM-dd` |
| 11 | 変数を設定 | 変数名: `日`、入力: 10 の「フォーマット済みの日付」（例: `2026-09-24`） |
| 12 | ヘルスケアサンプルを検索（Find Health Samples） | 種類: **歩数**。「フィルタを追加」→ **開始日** / 条件 **が次の範囲内**（is between）/ 変数 `開始` と 変数 `終了`。並べ替え・制限はそのまま（制限オフ） |
| 13 | 統計を計算（Calculate Statistics） | 操作: **合計**、入力: 12 の「ヘルスケアサンプル」 |
| 14 | 数値を丸める（Round Number） | 入力: 13 の「統計」、丸め: **1の位**（整数） |
| 15 | 変数を設定 | 変数名: `歩数`、入力: 14 の「丸めた数値」 |
| 16 | ヘルスケアサンプルを検索 | 種類: **ウォーキング＋ランニングの距離**。フィルタは 12 と同じ（開始日 が `開始` と `終了` の範囲内） |
| 17 | 統計を計算 | 操作: **合計**、入力: 16 の「ヘルスケアサンプル」 |
| 18 | 計算 | 17 の「統計」 `×` `1000`（ヘルスケアの距離単位が km の場合。m 表示なら 18 は不要で、19 の入力を 17 にする） |
| 19 | 数値を丸める | 入力: 18 の「計算結果」、丸め: **1の位** |
| 20 | 変数を設定 | 変数名: `距離`、入力: 19 の「丸めた数値」 |
| 21 | テキスト | 下の文字をそのまま打ち、`〔 〕` の部分は変数のバブルに置き換える（`〔 〕` 自体は打たない）: |
|   |   | `{"d":"〔日〕","steps":〔歩数〕,"distM":〔距離〕}` |
| 22 | 結果を表示（Show Result）※確認用 | 21 の「テキスト」。**確認後に削除** |
| 23 | 繰り返しの終了 | （3 を追加すると自動で入る） |
| 24 | テキストを結合（Combine Text） | 入力: 「繰り返しの結果」、区切り: **カスタム** `,`（半角カンマ1文字） |
| 25 | 変数を設定 | 変数名: `days` |

**確認（1-2）**: ▶ で実行 → 22 の表示が3回出て、1回目が今日の日付・歩数、2回目が昨日…になっていること。
歩数をヘルスケアアプリの「歩数」の各日の値と見比べ、メモする（ずれていたら iPhone＋Apple Watch の重複の可能性）。
- 6 に「日の始まりを取得」が無い場合: 6 を削除し、7 の入力を「10 と同じ `yyyy-MM-dd` にフォーマットした文字」にする（ショートカットは日付だけの文字を 0:00 として扱う）。その場合は並びを 5 → 10 → 7 → 8 → 9 → 11 にする。
- 数値の後ろに単位（`km` など）が付く、または小数点がカンマになる場合はメモする。

### 1-3 ワークアウト（過去3日）
| # | アクション | 設定 |
|---|---|---|
| 26 | ヘルスケアサンプルを検索 | 種類: **ワークアウト**。「フィルタを追加」→ **開始日** / **が過去**（is in the last）/ `3` **日** |
| 27 | 各項目を繰り返す（Repeat with Each） | 入力: 26 の「ヘルスケアサンプル」。以下 28〜32 は「各項目を繰り返す」と「繰り返しの終了」の**間**に入れる |
| 28 | 日付をフォーマット | 日付: 「繰り返し項目」を入れ、バブルをタップして **開始日** を選ぶ。日付フォーマット: **ISO 8601**、「時刻を含める」オン |
| 29 | 変数を設定 | 変数名: `s` |
| 30 | 日付をフォーマット | 日付: 「繰り返し項目」→ **終了日**。ISO 8601、時刻を含める オン |
| 31 | 変数を設定 | 変数名: `e` |
| 32 | テキスト | `{"s":"〔s〕","e":"〔e〕","type":"〔繰り返し項目の種類〕"}`。最後の `〔 〕` は「繰り返し項目」を入れてバブルをタップし **種類**（または「ワークアウトの種類」「アクティビティの種類」など近いもの）を選ぶ |
| 33 | 繰り返しの終了 | （自動） |
| 34 | テキストを結合 | 入力: 「繰り返しの結果」、区切り: カスタム `,` |
| 35 | 変数を設定 | 変数名: `workouts` |

**確認（1-3）**: 一時的に「結果を表示」で 34 の結果を出す。`{"s":"2026-09-23T18:00:00+09:00",…,"type":"…"}` のように見えればよい。
`type` に出た文字（例: 筋トレがどう表記されるか）をメモ。ワークアウトが3日間に無ければ空で正常。

### 1-4 コード化とコピー
| # | アクション | 設定 |
|---|---|---|
| 36 | 日付をフォーマット | 日付: 「現在の日付」、ISO 8601、時刻を含める オン |
| 37 | 変数を設定 | 変数名: `gen` |
| 38 | テキスト | `{"v":1,"gen":"〔gen〕","tz":"+09:00","days":[〔days〕],"workouts":[〔workouts〕]}` |
| 39 | Base64 エンコード（Base64 Encode） | モード: **エンコード**、入力: 38 の「テキスト」、改行: **なし** |
| 40 | 変数を設定 | 変数名: `b64` |
| 41 | テキスト | `〔鍵〕〔b64〕`（間に空白や改行を入れない） |
| 42 | ハッシュを生成（Generate Hash） | 入力: 41 の「テキスト」、種類: **SHA256** |
| 43 | テキストを置き換える（Replace Text） | 検索: `^(.{16}).*$`、置き換え: `$1`、対象: 42 の「ハッシュ」。「正規表現」**オン** |
| 44 | 変数を設定 | 変数名: `sig` |
| 45 | テキスト | `PH1.〔b64〕.〔sig〕` |
| 46 | クリップボードにコピー（Copy to Clipboard） | 入力: 45 の「テキスト」 |
| 47 | 通知を表示（Show Notification） | `PocketHeso に戻って貼り付けてください` |

**確認（1-4）**: PWA「spike: shortcut」→「ショートカットを開く」→ 通知 → 戻る →「貼り付け(read)」（失敗したらもう一度、それでもだめなら欄を長押し→ペースト）。
デコード欄に `days` 3件と `workouts` が出れば完成。初回はヘルスケアの許可画面が出るので、歩数・ウォーキング＋ランニングの距離・ワークアウトを許可する。
