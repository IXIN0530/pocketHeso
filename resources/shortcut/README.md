# PocketHeso Sync（iOS ショートカット）作成手順

仕様: docs/spec/31-shortcut-health.md。ショートカット名は **`PocketHeso Sync`**（PWA がこの名前で起動する）。
アクション名は iOS 26 日本語表示。表記が違う場合は近いものを選び、この README を直す。
iCloud 共有リンク: （P0-T3 の実機確認後に記入）

## 0. 最小版（P0-T3 の往復確認用）
先に往復（PWA → ショートカット → PWA → 貼り付け）だけ確かめる。
1. 「テキスト」: `PH1.eyJ2IjoxfQ.0000000000000000`（`{"v":1}` の Base64）
2. 「クリップボードにコピー」
3. 「通知を表示」: `PocketHeso に戻って貼り付けてください`

PWA を `?spike=shortcut` で開き →「ショートカットを開く」→ 通知後に PWA へ戻る →「貼り付け」。
デコード欄に `{"v":1}` が出れば成功。

## 1. 本番版
### 1-1 鍵
1. 「テキスト」: 鍵（16文字）。ショートカットの設定「読み込み時の質問」にこのテキストを登録する → 変数名 `鍵`

### 1-2 日ごとの歩数・距離（今日・昨日・一昨日）
2. 「繰り返す」回数 3。中で:
   1. 「日付を調整」: 現在の日付 から（繰り返しインデックス − 1）日 を引く
   2. 「日付をフォーマット」: カスタム `yyyy-MM-dd` → 変数 `日`
   3. 「ヘルスケアサンプルを検索」: 種類 = 歩数、開始日 が `日` の 0:00 から 1日以内（「今日」「過去 n 日」ではなく日付指定）
   4. 「統計を計算」: 合計 → 変数 `歩数`
   5. 同様に 種類 = ウォーキング＋ランニングの距離、単位 = m → 「統計を計算」合計 → 変数 `距離`
   6. 「テキスト」: `{"d":"<日>","steps":<歩数>,"distM":<距離>}`（小数は「数値を丸める」で整数に）
3. 「テキストを結合」: 区切り `,` → 変数 `days`

### 1-3 ワークアウト（過去3日）
4. 「ヘルスケアサンプルを検索」: 種類 = ワークアウト、開始日 が 過去 3 日以内
5. 「各項目を繰り返す」。中で:
   1. 開始日・終了日を「日付をフォーマット」ISO 8601（時刻を含める）
   2. 「テキスト」: `{"s":"<開始>","e":"<終了>","type":"<種類>"}`（`種類` はワークアウトの「種類」プロパティ）
6. 「テキストを結合」: 区切り `,` → 変数 `workouts`

### 1-4 コード化
7. 「日付をフォーマット」: 現在の日付, ISO 8601 → `gen`
8. 「テキスト」: `{"v":1,"gen":"<gen>","tz":"+09:00","days":[<days>],"workouts":[<workouts>]}`
9. 「Base64 エンコード」: 改行 = なし → 変数 `b64`
10. 「テキスト」: `<鍵><b64>` → 「ハッシュを生成」SHA256
11. 「テキストを置き換える」: 正規表現 `^(.{16}).*$` → `$1` → 変数 `sig`
12. 「テキスト」: `PH1.<b64>.<sig>` → 「クリップボードにコピー」
13. 「通知を表示」: `PocketHeso に戻って貼り付けてください`

## 2. 任意: オートメーション
「オートメーション」→「時刻」21:00 毎日 →「すぐに実行」→ アクション「ショートカットを実行: PocketHeso Sync」。
ロック後10分を過ぎるとヘルスケアが読めず失敗し得る（docs/ref/platform-limits.md）。
